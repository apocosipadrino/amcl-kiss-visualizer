AMCL vs Simple MCL (KISS) · Side-by-Side Localization
Two particle filters, one robot. Both filters receive the same motion commands and the same laser scans, so the only difference is the filter itself, and both start near the true pose. Simple MCL (KISS: Keep It Simple, Stupid) keeps a fixed number of particles and resamples when the effective sample size drops, with no adaptation. AMCL adds KLD-sampling, which grows or shrinks the particle count with uncertainty, and injects random particles when the sensor likelihood drops. Both track well at first — note how AMCL needs far fewer particles once confident. Then kidnap the robot: the simple filter usually stays lost, while AMCL recovers.
